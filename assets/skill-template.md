# 替换为任务名称

## 输入

列明必需输入；明确何时提问、何时可带假设继续。

## 配套知识

列明核心判断依赖的定义、模式或规则，以及内嵌/随包位置和读取时机。无知识支撑的判断标记缺口，不补造依据。

## 执行

按任务编写可执行步骤、分支、优先级和关键检查。
需要额外资源时给出相对路径及读取或执行的时机。

## 边界

写明不适用条件、失效信号和降级、停止或升级动作。

## 输出

定义用户应当拿到的结果及其格式。

## 检查

给出对结果可观察的检查标准。
