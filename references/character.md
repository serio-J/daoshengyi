# 角色线：行为与角色知识

默认输出可直接复制的自然语言角色 Prompt，不强制 Skill。
先确定用途（扮演、写作参谋等）、原作/原创、时间点与语言腔调；只问会改变结果的缺口。

## 内容层
- 驱动：想争取什么，害怕失去什么，底线是什么；从行为证据或用户设定建立，不固定三条。
- 性格：稳定反应倾向 + 支撑场景 + 不适用条件；一次行为不自动等于稳定人格。
- 思考：看哪些线索、如何解释、什么优先、触底线后如何切换，不只列形容词。
- 声音：句长、措辞、直接程度、温度、停顿；例句需区分原文与新创示例。
- 配套知识：所处世界、已知经历、关系、能力、时代/时间点、知道与不知道的事。
- 行为卡：情境 / 反应 / 机制 / 边界 / 出处。不是每个片段都必须造卡。

## 证据与生成
原作角色区分原文事实、用户补充设定、推断、同人变体。不得把原创台词冒充原作。
原创角色可在用户授权的创造范围内补充设定，但标明新增，不宣称有来源。
角色可以生成未发生过的对话，但不把生成内容升级成已发生的原作经历。
材料不足时限定角色范围与知识，不强编童年、动机或全知能力。
扮演人物不等于宣称是真人或获得其授权；遵守 safety.md 中的身份与隐私边界。

## 时间与关系
默认角色仅知道已确立时间点内可知之事；旁白信息不自动成为角色知识。
检验对陌生人、亲近者、敌对者以及底线触发时反应是否合理变化。
跨回合记忆能力取决于宿主；不要虚构持久记忆。

## 编译
小角色内嵌全部必需背景。长世界观可附资料并给读取时机；宿主不支持资料时提供缩减版并披露损失。
用户指定 Lisp 时只换表达，不改变驱动、知识或边界；无解释器时明确是 Lisp 风格 Prompt。
大量资料和工具编排才考虑 Skill；最终选择以用途和用户要求为准。
