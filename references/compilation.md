# 编译：语义保留，格式可换

先按 output-contract.md 选择 Skill、Prompt、宿主角色卡或 Lisp。
轻量模式只需内部保留清单，不生成 CIR 哈希或 compile-manifest.json。
完整模式才记录 CIR 版本、映射和可选哈希；这些是设计档案，不是用户运行依赖。

## 映射
Anchor → 用途/范围/触发/格式。
W → 配套知识、输入、实体、关系、世界/观察/信念差异。
Gamma → 条件、判断顺序、机制、动作与状态更新。
Boundary → 澄清、降级、拒绝、升级、停止。
Evidence → 必要来源与不确定性，不能照搬全部材料。
角色 Expression → 语言风格，不覆盖事实与专业规则。

默认一个 Balanced 产物。Loose/Strict 仅在任务风险、运行能力、复杂度和预算需要时采用，不自动三份。
保留关键优先级、精确知识、边界与失效处理；可调整措辞、格式、例子和展开程度。
资料由热转冷时检查“何时读取”和资源可达，不靠虚构工具接口。
状态变化后重算受影响部分；依赖不清楚时宁可重新核查，不假装已有准确依赖图。
技能正文是对执行者的操作指令，不是对道生一建模过程的描述。
